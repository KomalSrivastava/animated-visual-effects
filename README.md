# Three.js Scratch Effect Project

## Overview
This project implements a visually engaging background animation using Three.js alongside a scratch effect that reveals letters in a text. The animation is designed to create an interactive and dynamic user experience.

## Features
- **Three.js Particle System**: A rotating particle system with customizable colors.
- **Scratch Effect**: Interactive text that changes color as users hover over it.
- **Responsive Design**: The layout adjusts smoothly to different screen sizes.
- **Customizable Animations**: CSS animations for various elements to enhance visual appeal.
- **GSAP Animation**: Utilizes GSAP (GreenSock Animation Platform) for additional animations.

## Technologies Used
- HTML
- CSS
- JavaScript
- Three.js
- GSAP
